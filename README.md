# MediCare Hospital
An assignment approaching the **management system** of a hospital wherein there is a transition from paper to digital in order to **modernize** the approach of the business

## Problem & Context
Medicare is using an archaic method of data storage and retrieval, so we have these questions:

- 🎯 **Why transition:** *Why should MediCare change over to a digital approach?*
- 🤔 **What does the transition imply:** *what solution is being implemented to modernize MediCare's system?*
- 📈 **How does the transition improve Medicare:** *what added benefits are achieved by conversion to a digital system?*

**So why change to a digital approach?**
-  ✅ Greater efficiency
-  ✅ Improved retrieval of data
-  ✅ Reduced physical filing and sorting
-  ✅ No human error
-  ✅ QoS

This problem requires a more **sophisticated** system therefore a digital approach is required.
